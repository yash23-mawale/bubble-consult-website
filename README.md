# Bubble Consult

A modern and responsive business consulting website built using HTML, CSS, and JavaScript to help businesses attract clients and improve online engagement.

## Features

* **Responsive Design:** Works across mobile phones, tablets, and desktops.
* **Modern UI:** Clean and professional business website layout.
* **Testimonials Carousel:** Navigate through customer reviews using Previous/Next buttons with automatic rotation every 5 seconds.
* **Contact Form:** Form validation for required fields and email format.
* **Confirmation Message:** Displays a thank-you message after successful form submission.
* **Lead Generation:** Contact section and social media links for connecting with potential clients.

## Tech Stack

* HTML5
* CSS3
* JavaScript

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/bubble-consult.git
   ```

2. Navigate to the project folder:

   ```bash
   cd bubble-consult-website
   ```

3. Open `index.html` in your browser to view the website.

   You can also use the Live Server extension in Visual Studio Code.

## Project Objective

This project was developed as part of a business consulting website case study, focusing on responsive design, customer testimonials, and contact form validation.
